## Sonap route (default)
1. Load the Sonap tools with ToolSearch (`mcp__Sonap__*`). Channel: **"Honey Bunny Kidz" YouTube, id `adfe09aa-76f1-48e7-940e-cbdf839012ad`** (confirm with `list_channels`; never use the other channels on the desk: කලටි පොල්, Political Exposed, E Positive, Mimzi).
2. Media: call `media_storage` with that channel_id.
   - If it reports GitHub storage for this channel (repo honey-bunny-kidz/honeybunny-media), pass `github_path` = `videos/<file>.mp4` (no size limit).
   - Otherwise pass `media_url` = the raw.githubusercontent.com URL. `media_url` imports are limited to **25 MB**: re-encode first if needed, e.g. `ffmpeg -i in.mp4 -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -c:a aac -profile:a aac_low -b:a 96k -movflags +faststart out.mp4` (5:20 episode -> ~22 MB; raise crf to 32–34 for longer videos). Use AAC-LC audio (Sonap: xHE-AAC often fails on YouTube). Commit the smaller file over videos/<file>.mp4 so the URL serves it.
3. `schedule_post` with channel_ids [that id], `scheduled_at` in UTC ISO-8601 (daily episode 17:30 Asia/Colombo = 12:00Z; mini compilation 17:00 = 11:30Z; Sunday compilation 16:00 = 10:30Z; if the time has passed, ~30 min from now), `title` = the YouTube title (≤100 chars), `body` = the YouTube description (2–3 lines for parents + chapters + "👍 Follow us on Facebook: https://facebook.com/1432376496625170" + hashtags), `timezone` "Asia/Colombo", plus `media_url`/`github_path`, `filename`, `mime` "video/mp4".
3b. Do NOT pass `tags` to schedule_post: Sonap splits them into single-word hashtags (#for #kids ...) appended to the description. Keep 4–6 hashtags inside the body instead.
3c. Two-step form that works (2026-11-22): `import_media` with `github_path` "videos/<file>.mp4" (+ `destination` "github") returns a media id; then `schedule_post` with `media_ids` [that id].
4. Sonap has no fields for made-for-kids, the AI-content label, custom thumbnail or captions: in the summary, give the user the thumbnail link and .srt link and remind them to set "Made for kids" + "Altered or synthetic content" + thumbnail in YouTube Studio (once per video) unless Sonap later adds these options.
5. Log `"youtube_long": "sonap"` and `"sonap_post_id": "<id>"` in log.json. The daily cleanup may delete the video from GitHub once `list_posts` shows that Sonap post as `published` (delivery_status published); if it is `failed`, keep the file and report it.
6. If Sonap fails (e.g. "Token has been expired or revoked", tool missing in this task), keep the file, log `"youtube_long": "manual upload by user"` and list the manual upload details (title, description, tags, video, thumbnail and .srt links) in the summary, plus the Sonap error.
